# Дорожная карта UX/UI: Apart.kg (ориентир — house.kg)

Решения зафиксированы по итогам анкеты от 12.05.2026. Это **рабочий чек-лист**, добавляем/правим только пункты, ничего не выбрасываем без записи.

---

## 0. Решения, которые мы УЖЕ приняли

| Тема | Решение |
|------|---------|
| Главная цель спринта | **Визуал**: типографика, отступы, цвета, скелетоны, аккуратные анимации |
| Карточка в ленте | **Крупная** (как сейчас): фото сверху, текст снизу |
| Фильтр комнат | Обычный **select** в фильтрах |
| Валюта | **Переключатель в шапке**: $ / KGS / ¥ с пересчётом по курсу |
| Главная (под фильтрами) | Две колонки **Продажа / Аренда**, далее блок **Новостройки**, далее **Топ агентства** |
| Агентства | **Полный модуль**: каталог компаний + профиль + бейдж «агентство» у автора |
| Бейджи | Метка **«срочно»** + **VIP / TOP / Премиум** с короткими подсказками |
| Контакты | Кнопка **«Заказать обратный звонок»** на карточке/в модалке |
| Основной язык | **Русский** (но переключатель остаётся) |
| Объём | **Большой**: идём по всему плану до конца |

## 1. Чек-лист задач (по фазам)

Формат: `[ ] описание (где в коде → критерий «готово»)`

### Фаза A. Визуальная база (главная цель)

- [x] **Дизайн-токены** в `frontend/styles.css`: шкала отступов (4/8/12/16/24/32/48), радиусы (8/12/16/20), 3 уровня тени, типографические `--fs-*`, кривые анимаций  
- [x] **Типографика** — Manrope в HTML, `--fs-caption/body/lead/h3/h2/h1` через `clamp()`  
- [x] **Скелетоны загрузки** — `.skeleton-card` в ленте, избранном, рейлах главной  
- [x] **Пустые состояния** — `.state-block` с кнопкой «Сбросить фильтры» и «К объявлениям»  
- [x] **Состояние ошибки сети** — кнопка «Повторить» прямо в списке  
- [x] **Анимации сдержанные** — `prefers-reduced-motion` уже уважался, новых «прыгающих» не добавлено  
- [x] **Доступность** — универсальный focus-ring, Enter/Space на карточках, `aria-label` на сердечке и переключателях

### Фаза B. Каталог как у портала

- [x] Сегмент **«Продажа / Аренда»** на главной (две горизонтальные ленты + «Все объявления»)  
- [x] **Фильтр комнат** — chip-row «Любое / Студия / 1 / 2 / 3 / 4 / 5+ / Свободная»; backend нормализует через `parseRoomsCategory`  
- [x] **Переключатель валюты в шапке** `KGS / $ / € / ¥ / ₽` (localStorage `apartCurrency`, курсы из `/api/config.currency`)  
- [x] **Бейдж «срочно»** в карточке (`.badge--urgent`)  
- [x] **Бейджи VIP / TOP / Премиум / Агентство** в карточке (`.badge--vip / --top / --premium / --agency`) — отображаются по полям `vipUntil / topUntil / premiumUntil` (бэкенд под Фазу F)

### Фаза C. Главная и навигация

- [x] Блок **Новостройки** на главной — превью комплексов с % прогресса, клик → `view-newbuilds`  
- [x] Блок **Топ агентства** на главной — рейл с переходом «Все агентства» (через `GET /api/agencies`)  
- [x] CTA-кнопка **«Показать на карте»** рядом с фильтрами (`#btnShowOnMap` → `setView("map")`)  
- [x] Хлебные крошки в модалке объявления (Главная › Продажа/Аренда › Тип › Район)  
- [x] Блок **«Похожие объявления»** в модалке (`GET /api/listings/:id/similar`)  
- [x] На широких экранах модалка объявления — двухколоночная: контент слева, контакты+агентство+действия справа

### Фаза D. Агентства (модуль)

- [x] Поля агентства добавлены к `User` (миграция `20260513090000_agency_profile`): `isAgency`, `agencyName`, `agencySlug` (unique), `agencyLogo`, `agencyDescription`, `agencyCity`  
- [x] API: `GET /api/agencies` (поиск + сортировка по рейтингу/числу объявлений), `GET /api/agencies/:slug` (профиль + лента активных объявлений)  
- [x] Фронт: view `agencies` — каталог карточек с поиском; view `agency` — шапка профиля + лента объявлений автора  
- [x] Бейдж **«Агентство»** у автора в карточке и в модалке + переход на профиль одной кнопкой
- [x] Форма **«Стать агентством»** в `view-more` (`#agencyProfileCard`) с полями имя/slug/город/лого/описание; `PATCH /api/auth/me` принимает агентство-поля, slug автогенерируется и проверяется на уникальность

### Фаза E. Контакты и обратный звонок

- [x] Модель **`CallbackRequest`** + миграция (`20260513110000_callback_promo`)  
- [x] API: `POST /api/callbacks` (создаёт заявку + push владельцу через `notifyUser`), `GET /api/callbacks?role=owner|mine`, `PATCH /api/callbacks/:id` (смена статуса)  
- [x] Кнопка **«📞 Обратный звонок»** в модалке объявления + отдельная модалка-форма (`#modalCallbackForm`)  
- [x] В `view-more` карточка **«Заявки на обратный звонок»** с табами «Входящие / Мои заявки» и кнопками статуса (Связался / Готово / Отменить)

### Фаза F. Монетизация VIP / TOP / Премиум

- [x] Поля `vipUntil`, `topUntil`, `premiumUntil`, `priorityScore` на `Listing` (та же миграция)  
- [x] Витрина тарифов **TOP / VIP / Премиум**: `GET /api/promo/tiers` отдаёт цены, длительность, перки  
- [x] `POST /api/promo/activate` — пересчитывает `priorityScore`, продлевает соответствующий `*Until`, создаёт `Payment(status=PAID, provider=DEMO)` для истории  
- [x] Сортировка ленты `routes/listings.js` — `orderBy: [priorityScore desc, createdAt desc]`  
- [x] Бейджи **TOP / VIP / Премиум** в карточке и в модалке + tooltip с пояснением  
- [x] В `view-more` карточка **«Продвижение объявлений»** — выбор объявления и активация тарифа в один клик (demo)

## 2. Визуальное направление (зафиксировано)

| Параметр | Решение |
|----------|---------|
| Темы | **Тёмная + светлая равноценны**, пользователь выбирает в шапке |
| Акцентный цвет | **Зелёный/бирюзовый** (доверие, недвижимость) |
| Плотность | **Сбалансированная**: адаптивно по ширине экрана |
| Шрифт | **Manrope** (или Onest как fallback) |
| Референсы | **Airbnb** (воздух, фото, скругления) + **Lianjia** (плотность, бейджи) |
| Порядок работ | По порядку из чек-листа (Фаза A → B → C → D → E → F) |

## 3. Принципы

1. **Один источник правды** — этот файл. Идея появилась — пунктом сюда, не в чат.  
2. **Критерий «готово»** обязателен у каждой задачи.  
3. **Копируем логику, не пиксели** — палитра и стиль остаются вашими.  
4. **Сначала ядро каталога, потом монетизация.** Иначе нечего продавать.
