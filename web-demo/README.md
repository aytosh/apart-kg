# Веб-демо Apartmant

Одностраничное приложение в браузере (без сервера и бэкенда). Данные объявлений и избранное хранятся в **localStorage** этого браузера.

## Что работает

| Экран | Действия |
|-------|----------|
| **Главная** | Поиск по тексту, фильтры «Аренда / Продажа», тип объекта, карточки, избранное (сердечко), тап по карточке — детальное окно |
| **Карта** | OpenStreetMap + Leaflet, метки по объявлениям (те же фильтры, что на главной), клик по метке — карточка |
| **Разместить** | Форма нового объявления → сохранение в localStorage, появление в списке и на карте |
| **Избранное** | Список сохранённых объявлений |
| **Ещё** | Имя пользователя, сброс локальных данных |
| **Уведомления** | Всплывающее сообщение (демо) |
| **Деталь** | «Позвонить» (ссылка `tel:`), «Написать» (демо-тост) |

Нужен **интернет** для загрузки Leaflet, тайлов карты OSM и картинок Unsplash.

## Запуск локально

Из папки `web-demo`:

**Python**

```bash
cd web-demo
python -m http.server 8080
```

Откройте: http://localhost:8080

**Node**

```bash
cd web-demo
npx --yes serve -l 8080
```

Открытие `index.html` с диска иногда ограничивает карту и скрипты — лучше через локальный сервер.

## Файлы

- `index.html` — разметка и экраны
- `styles.css` — стили
- `app.js` — логика, хранилище, карта, модальное окно

Это **демо для UX**; продакшен — отдельный бэкенд, авторизация, платежи, модерация.
